# YF Download

**مدير تحميل حر ومفتوح المصدر، يُسرّع التحميل بتقسيم الملفات إلى أجزاء متوازية، مع واجهة أنيقة تدعم العربية أولًا.**

بديل مجاني وشفّاف لبرامج التحميل المغلقة — يعمل على ويندوز ولينكس.

>

## ما هو YF Download؟

مدير تحميل مكتوب بـ Rust، بواجهة Tauri + Svelte، يهدف إلى:

- **تسريع التحميل** بتقسيم كل ملف إلى أجزاء تُحمَّل في وقت واحد (تحميل متعدد الاتصالات).
- **استئناف التحميل** بعد انقطاع الإنترنت أو إيقاف التشغيل.
- **التكامل مع المتصفحات** (Chrome، Firefox، Edge) لالتقاط روابط التحميل تلقائيًا.
- **جدولة التحميل** والتنظيم بفئات.
- **واجهة عربية أولًا** مع دعم الإنجليزية بضغطة زر.

# YF Download

**A free, open-source download manager that accelerates downloads by splitting files into parallel segments, with a beautiful Arabic-first UI.**

A free and transparent alternative to proprietary download managers — runs on Windows and Linux.

> **⚠️ Status: Under Construction**
>
> This project is in its early stages. Currently only foundation files and documentation exist.
> No code has been written yet, and there is no usable release.
