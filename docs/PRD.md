# وثيقة متطلبات المنتج (PRD) — YF Download

**الإصدار:** 0.1 (مسودة)
**التاريخ:** نوفمبر 2026
**الحالة:** قيد المراجعة

---

## 1. ملخص المنتج

**YF Download** هو مدير تحميل مجاني ومفتوح المصدر، مكتوب بـ Rust مع واجهة Tauri + Svelte.
يُسرّع تحميل الملفات بتقسيمها إلى أجزاء تُحمَّل بالتوازي عبر اتصالات متعددة، مع دعم استئناف التحميل والتكامل مع المتصفحات.

يعمل على **ويندوز ولينكس**، بواجهة **عربية أولًا** مع دعم الإنجليزية.

## 2. من المستخدم المستهدف؟

| الفئة | الوصف |
|-------|-------|
| **المستخدم العادي** | يريد تحميل ملفات بسرعة بدون تعقيد، يفضّل واجهة عربية. |
| **المستخدم المتقدم** | يريد تحكمًا أكبر: جدولة، فئات، تحميل دفعي، حدود سرعة. |
| **مستخدم لينكس** | يبحث عن مدير تحميل قوي بواجهة رسومية لنظامه (البدائل محدودة). |
| **المطوّر/المساهم** | يريد مشروعًا مفتوح المصدر مكتوبًا بتقنيات حديثة للمساهمة فيه. |

## 3. ما يفعله المشروع (النطاق — Scope)

### 3.1 الميزات الأساسية (Core Features)

| # | الميزة | الوصف |
|---|--------|-------|
| F1 | **تحميل متعدد الاتصالات** | تقسيم كل ملف إلى أجزاء (segments) تُحمَّل بالتوازي لتسريع التحميل. |
| F2 | **استئناف التحميل** | عند انقطاع الإنترنت أو إيقاف التحميل، يُستأنف من حيث توقف (إذا دعم الخادم ذلك عبر HTTP Range). |
| F3 | **قائمة انتظار (Queue)** | تنظيم التحميلات في قائمة مع تحكم في عدد التحميلات المتزامنة. |
| F4 | **واجهة رسومية** | واجهة Tauri + Svelte حديثة وخفيفة، تدعم RTL للعربية. |
| F5 | **دعم البروتوكولات** | HTTP وHTTPS أساسًا، مع إمكانية إضافة FTP لاحقًا. |
| F6 | **إعدادات** | تحكم بمجلد الحفظ، عدد الاتصالات، حد السرعة، اللغة. |

### 3.2 الميزات الثانوية (مراحل لاحقة)

| # | الميزة | الوصف |
|---|--------|-------|
| F7 | **إضافة متصفح (Browser Extension)** | إضافة لـ Chrome/Firefox/Edge تلتقط روابط التحميل وتمررها إلى YF Download. |
| F8 | **جدولة التحميل** | تحديد وقت بدء التحميل أو إيقافه تلقائيًا. |
| F9 | **تصنيف بفئات** | تنظيم التحميلات في فئات (فيديو، موسيقى، مستندات، برامج…). |
| F10 | **تحميل دفعي** | إدخال قائمة روابط وتحميلها جميعًا. |
| F11 | **تحديد سرعة التحميل** | حد أقصى للسرعة حتى لا يستهلك كل النطاق الترددي. |
| F12 | **تحميل فيديو من صفحات الويب** | اكتشاف روابط الفيديو في صفحة ويب وعرضها للتحميل. |
| F13 | **دعم FTP** | إضافة دعم بروتوكول FTP. |

## 4. ما لا يفعله المشروع (خارج النطاق — Out of Scope)

| # | ما هو خارج النطاق | السبب |
|---|-------------------|-------|
| X1 | **تحميل التورنت (BitTorrent)** | بروتوكول مختلف تمامًا، له برامج متخصصة. |
| X2 | **خادم تحميل (Download Server)** | المشروع هو عميل فقط، لا يخدم ملفات للآخرين. |
| X3 | **تخزين سحابي** | لا يرفع ملفات إلى السحابة ولا يتكامل مع خدمات التخزين السحابي. |
| X4 | **دعم macOS** | ليس في النطاق الحالي (ويندوز ولينكس فقط). يمكن إضافته مستقبلًا. |
| X5 | **دعم أندرويد/iOS** | ليس في النطاق. |
| X6 | **محتوى محمي بـ DRM** | لا يتجاوز حماية المحتوى الرقمي. |
| X7 | **التقاط حزم الشبكة (Packet Sniffing)** | لا يراقب حركة الشبكة للبحث عن تحميلات. يعتمد على التكامل مع المتصفح. |

## 5. المتطلبات غير الوظيفية

| المتطلب | الوصف |
|---------|-------|
| **الأداء** | يجب أن يصل لسرعة تحميل قريبة من أقصى سرعة الاتصال مع 8-16 اتصالًا متوازيًا. |
| **استهلاك الموارد** | استهلاك ذاكرة أقل من 100 MB أثناء التحميل النشط، وأقل من 30 MB في الخمول. |
| **حجم التطبيق** | أقل من 30 MB (بفضل Tauri بدلًا من Electron). |
| **الأمان** | التحقق من شهادات TLS، تنظيف المدخلات، عدم تخزين أسرار في الكود. |
| **إمكانية الوصول** | دعم RTL كامل، أحجام خطوط قابلة للتعديل. |
| **التوافقية** | ويندوز 10+ ولينكس (Ubuntu 20.04+، Fedora 36+، Arch). |

## 6. قصص المستخدم (User Stories)

### المستخدم العادي
- **كمستخدم**، أريد أن أضغط رابط تحميل في المتصفح فيفتح YF Download تلقائيًا ويبدأ التحميل.
- **كمستخدم**، أريد أن أرى شريط تقدم واضح مع السرعة والوقت المتبقي.
- **كمستخدم**، أريد أن أوقف تحميلًا وأستأنفه لاحقًا دون إعادة التحميل من البداية.
- **كمستخدم عربي**، أريد واجهة عربية واضحة من أول تشغيل بدون إعدادات.

### المستخدم المتقدم
- **كمستخدم متقدم**، أريد التحكم في عدد الاتصالات المتوازية لكل تحميل.
- **كمستخدم متقدم**، أريد تحديد سرعة التحميل حتى لا يبطئ تصفحي.
- **كمستخدم متقدم**، أريد جدولة التحميل ليبدأ في وقت محدد (مثلًا: الليل).

## 7. مقاييس النجاح

| المقياس | الهدف |
|---------|-------|
| سرعة التحميل | ≥ 90% من أقصى سرعة الاتصال مع ملف كبير (> 100 MB) |
| وقت بدء التطبيق | < 2 ثانية |
| نسبة نجاح الاستئناف | 100% مع خوادم تدعم HTTP Range |
| استهلاك الذاكرة أثناء الخمول | < 30 MB |
