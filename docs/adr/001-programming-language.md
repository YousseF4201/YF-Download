# ADR-001: لغة البرمجة الأساسية

**الحالة:** مقترح — ينتظر الموافقة
**التاريخ:** نوفمبر 2026

## السياق

نحتاج لاختيار لغة البرمجة الأساسية لنواة مدير التحميل YF Download.
المشروع يتطلب:
- أداء عالٍ في عمليات الشبكة والملفات.
- تعدد مهام (concurrency) لتحميل أجزاء متعددة بالتوازي.
- أمان ذاكرة لتجنب الثغرات.
- قابلية البناء على ويندوز ولينكس.

## الخيارات

### 1. Rust ✅ (الاختيار)
| الجانب | التقييم |
|--------|---------|
| الأداء | ممتاز — يقارب C/C++ |
| أمان الذاكرة | ممتاز — مضمون في وقت الترجمة (borrow checker) |
| تعدد المهام | ممتاز — tokio يوفر async/await مع أداء عالٍ |
| مكتبة HTTP | ممتازة — reqwest (مبنية على hyper) |
| التوافق مع Tauri | أصلي — Tauri مكتوب بـ Rust |
| منحنى التعلم | عالٍ — لكنه استثمار طويل المدى |
| المجتمع | نشط ومتنامي |

### 2. Go
| الجانب | التقييم |
|--------|---------|
| الأداء | جيد — أبطأ من Rust بقليل |
| أمان الذاكرة | جيد — garbage collector |
| تعدد المهام | ممتاز — goroutines |
| التوافق مع Tauri | ضعيف — يحتاج FFI أو عملية منفصلة |
| منحنى التعلم | منخفض |

### 3. C++
| الجانب | التقييم |
|--------|---------|
| الأداء | ممتاز |
| أمان الذاكرة | ضعيف — مسؤولية المطور |
| تعدد المهام | معقد |
| التوافق مع Tauri | ممكن لكن معقد |
| الصيانة | صعبة |

### 4. Python
| الجانب | التقييم |
|--------|---------|
| الأداء | ضعيف — غير مناسب لعمليات I/O مكثفة بهذا الحجم |
| التوافق مع Tauri | ضعيف |

## القرار

**Rust** — لأنه:
1. يتوافق أصلًا مع Tauri (لا حاجة لجسر بين لغتين).
2. أمان الذاكرة مضمون في وقت الترجمة، وهذا مهم لتطبيق يتعامل مع بيانات من الإنترنت.
3. أداء ممتاز في عمليات الشبكة والملفات (مع tokio وreqwest).
4. المشروع طويل الأمد، ومنحنى تعلم Rust العالي يُعوَّض بأمان وصيانة أسهل.

## العواقب

- يجب أن يتعلم المساهمون أساسيات Rust.
- وقت الترجمة أطول من لغات أخرى (يُخفف بـ incremental compilation).
- مجتمع المساهمين قد يكون أصغر من Python أو JavaScript.
